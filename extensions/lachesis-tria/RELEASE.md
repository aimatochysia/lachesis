A tile library for pixel art, like an asset library. Slice tiles out of what is visible on the canvas on a grid you set (x, y, tile width, tile height), and keep them in named groups that every project can use. Empty and duplicate tiles are skipped. Browsing the library and stamping tiles onto a layer are coming next.

**Menu: File > Scripts > Tile Library**
- **Capture Tiles From Canvas...**: set the grid, untick any tiles you don't want, then save them to a group.
- **Tile Library Settings...**: choose where the library folder lives (Aseprite's config folder by default).
