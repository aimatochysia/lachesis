Remembers which sprites you have open and reopens them the next time Aseprite starts, like a browser restoring its last tabs. It saves the list every 2 minutes and when you quit, never opens a file twice, and skips files that were moved or deleted.

**Menu: File > Scripts > Session Restore**
- **Restore Last Session on Launch**: the on/off switch (on by default).
- **Reopen Last Session Now**: reopens the saved files right away, skipping ones already open.
- **Session Restore Settings...**: save interval and the optional crash-safe session file.
